**New**
- Help › Check for Updates: the app tells you when a newer version is out. Help › Report a Bug and Request a Change send a message straight from the app. ♥ Donate in the top bar.
- Right-click menu in the 3D view: group, face and selection commands, plus Select › Connected, Same Material or Component, Same Tag.
- Rows of copies: copy with Move or Rotate (hold ⌥ / Ctrl), then type 5x for five copies or /5 to fill the gap.
- Point tracking: touch a corner, then an axis line stops level with it ("From Point"). Lines snap square to sloped edges too.
- Text labels offer a face's area, an edge's length or a group's name.
- Edit › Reverse Faces and Orient Faces; Solid Tools › Outer Shell; View › Hide Rest of Model.
- Paint Bucket › Sample picks up a material from the model.
- Dimensions and notes follow the geometry they are on when it moves, flips or is pushed.
- Shadow settings are saved in the model and in scenes.
- Moved drawing axes now set the ground you draw on.

**Notes**
- The macOS app is not notarized and the Windows files are not code-signed yet (see the README for the first start).
