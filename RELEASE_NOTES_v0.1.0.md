First public desktop build of GSketch.

**Highlights**
- SketchUp-style modelling: lines, arcs, rectangles, circles, polygons, freehand; push/pull, Follow Me, offset, move, rotate, scale, Solid Tools (union, subtract, intersect), Intersect Faces.
- Inference snapping (endpoints, midpoints, edges, faces, axes, parallel / perpendicular), guide lines, protractor, and typed sizes with units and math (`4'6"`, `1in + 5mm`, `width - 2*t`).
- Groups and components, tags, scenes, outliner, section planes, shadows with time of day, X-ray and wireframe, dimensions and text.
- Woodworking: cabinet builder, cut list and printable cut sheet, Send to GCarve (flat panels by thickness).
- Open SketchUp COLLADA (.dae) and STL exports, OBJ, DXF and SVG; export STL, COLLADA, image, panels as SVG / DXF.
- Works without a three-button mouse: trackpad swipe orbits, pinch zooms, ⌥ / ⌃ / ⌘ + drag orbit / pan / zoom. SpaceMouse supported.
- Crash recovery: unsaved work is offered back at the next start.

**Notes**
- No account needed on the desktop; signing in adds cloud models shared with gsketch.app.
- macOS app is not notarized and Windows files are not code-signed yet (see the README for the first start).
- The Linux ARM64 build is untested on real hardware; Windows builds were self-checked under Wine; the 32-bit Windows 7 build has not been run on a real PC yet.
