**New**
- Help › Check for Updates › **Update now**: downloads the right file for your computer and opens it, with the install steps. If the download or opening fails, the download page opens in your browser instead.
- Edit › Isolate Selection: hide everything but what is selected (Unhide All brings it back).
- File › Export Sheets for CNC (DXF or SVG): the sheet layout as a cut file, each sheet's parts on its own layer and the sheet edges on another, ready for GCarve. The printable Sheet Layout and the cut file use the same placement.

**Notes**
- From 0.1.3, use Help › Check for Updates › Download, or the download page; from 0.1.4 on, Update now does it for you.
- The macOS app is not notarized and the Windows files are not code-signed yet (see the README for the first start).
